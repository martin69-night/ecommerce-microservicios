# Colección Postman

En esta carpeta se debe guardar la colección exportada desde Postman.

Nombre sugerido:

DSY1103-Ecommerce-Microservicios.postman_collection.json

La colección debe incluir:

1. Crear producto.
2. Agregar producto al carrito usando cart-service con Feign hacia catalog-service.
3. Crear inventario.
4. Crear pedido usando order-service con Feign hacia inventory-service.
5. Confirmar stock reservado.
6. Crear pago.
7. Aprobar pago.
8. Error 404 controlado.
9. Error 400 controlado.
10. DELETE 204 No Content.
